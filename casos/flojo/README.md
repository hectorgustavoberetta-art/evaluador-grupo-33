# Caso deficiente

Este caso representa un trabajo que presenta incumplimientos importantes respecto de los criterios establecidos en la rúbrica.

## Características

- Cumple solamente una parte menor de la consigna.
- Presenta una estructura poco clara o desordenada.
- No fundamenta adecuadamente sus decisiones.
- Utiliza de manera incorrecta o incompleta las herramientas solicitadas.
- Presenta evidencias insuficientes o difíciles de verificar.
- La documentación no permite comprender o reproducir adecuadamente el trabajo.

## Resultado esperado

El agente evaluador debería asignar a este trabajo una calificación baja, justificando la evaluación de acuerdo con los criterios definidos en la rúbrica e identificando claramente los principales incumplimientos y aspectos que deben mejorarse.
